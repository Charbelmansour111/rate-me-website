# App screenshots

Drop portrait screenshots here and rebuild; no code changes. Until a file exists, the site draws a
sketch in its place. Which screens show, and in which order, is set in `src/config/screens.config.ts`.

| Coach view                   | Player view        |
| ---------------------------- | ------------------ |
| `coach-home.png`             | `player-home.png`  |
| `coach-calendar.png`         | `player-event.png` |
| `coach-whiteboard.png`       | `player-card.png`  |
| `coach-whiteboard-roles.png` |                    |
| `coach-formation.png`        |                    |
| `coach-squad.png`            |                    |
| `coach-card.png`             |                    |
| `coach-channel.png`          |                    |

- `.webp` and `.jpg` work too. Size: 9:19.5, such as 1170 x 2532 px.
- For the Arabic page add `coach-home.ar.png` and so on. Without them it uses the files above.
- Demo data only: no real players' names, photos or ratings.
- Players have no channel in the app, so there is no channel in the player view.
